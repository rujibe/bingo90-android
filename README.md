# Bingo 90 para Android

Aplicación Android para cartones de bingo español de 90 bolas.

## Funciones
- Crea 1.000 cartones válidos al primer inicio.
- Toca los números para marcarlos o desmarcarlos.
- Los cartones y las marcas se guardan localmente en el teléfono.
- Crea cartones propios introduciendo 15 números distintos del 1 al 90 (respetando las columnas del bingo de 90 bolas).
- Añade cartones aleatorios y cambia de cartón desde la lista.
- No extrae bolas ni requiere conexión a Internet para jugar.

## Generar el APK desde el móvil
1. Abre la pestaña **Actions** de este repositorio: https://github.com/rujibe/bingo90-android/actions
2. Entra en el flujo **Construir APK de Bingo 90**.
3. Pulsa **Run workflow** y confirma.
4. Espera a que termine correctamente (marca verde).
5. Abre esa ejecución y busca **Artifacts** al final.
6. Descarga **Bingo90-APK.zip**, descomprímelo y abre `app-debug.apk` en Android para instalarlo. Puede que Android te pida permitir la instalación desde el navegador o desde Archivos.

El APK de depuración sirve para instalar y probar la aplicación. GitHub Actions lo conserva durante 14 días por ejecución.
